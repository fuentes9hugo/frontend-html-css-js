# ¡RETO!

Después de terminar el modulo, realiza mediante HTML, CSS y JS un conversor de monedas para nuestros viajes alrededor del mundo.

Tendremos que realizar los siguientes pasos:

1. Diseñar un formulario con HTML y CSS para la introducción de la moneda que vayamos a querer convertir:
    - Input de entrada con la cantidad
    - Botón de conversión

2. Programar con JS la conversión de la moneda:
    - Capturar el evento del botón
    - Convertir AL MENOS EN 3 MONEDAS
    - Mostrar el resultado por Log

3. Realizar las siguientes comprobaciones y lanzar un mensaje de error al usuario si se produce:
    - Comprobar que no está vacío
    - Comprobar que la cantidad no es menor a 0
    - Comprobar que es un número (investigad como realizarlo)

### Modificación del reto

Si quieres más, en vez de mostrar las conversiones por log, crea 3 inputs en vuestro diseño y saca las conversiones en esos inputs.

#### Aún mucho más
Y si aún te quedas con ganas, puedes incluso permitir al usuario la moneda de origen con un selector de moneda.
